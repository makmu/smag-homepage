# Use Tailwind CSS for Styling

We will use **Tailwind CSS** as the primary styling framework for the frontend application.

## Context

The team needs a cost-effective, maintainable, and rapid way to style the user interface. The project is small, and we want to avoid the overhead of heavy component libraries or the complexity of managing large custom CSS codebases.

In 2026, we still believe that Tailwind CSS is the most cost-effective way to handle styling.

## Considered Alternatives

*   **Native CSS**: Rejected due to the steeper learning curve and higher maintenance effort required to organize and scale raw CSS.
    *   *Note*: This decision may be revisited in the future if AI coding agents become the primary method for managing CSS, mitigating the manual maintenance burden.
*   **Bootstrap / Heavy UI Frameworks**: Rejected because they are considered "overkill" for a website of this size. Additionally, their usage is declining compared to utility-first frameworks, raising concerns about long-term maintenance and modernization.
